# 🎵 SoundFlow - UPDS

Aplicación web reproductora de música y video UPDS.

## 📖 Descripción

SoundFlow es un reproductor multimedia que permite reproducir archivos de audio y video, gestionar listas de reproducción y controlar la reproducción mediante una interfaz responsiva y moderna.

## 🛠️ Tecnologías utilizadas

- **HTML5** – Estructura semántica y elementos `<audio>` / `<video>`
- **CSS3** – Estilos, Flexbox/Grid, diseño responsivo
- **JavaScripES6+)** – Lógica del reproductor y manipulación del DOM
- **Figma** – Diseño y vizualizacion general
- **Git & GitHub** – Control de versiones colaborativo
